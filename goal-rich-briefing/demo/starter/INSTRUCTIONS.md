# Demo — Anatomy of a Goal-Rich Brief

*Instructor demo brief. Estimated running time ~8 minutes. The full worked version is in [`../solution/walkthrough.md`](../solution/walkthrough.md).*

## Setup

- **Product:** a freemium productivity SaaS. The marketer runs lifecycle and conversion messaging.
- **Tool:** Claude Code.
- **Input:** no dataset. The demo starts from one throwaway prompt (below) and rewrites it live.

**Starting prompt to type on screen:**
> "Write an email to get free users to upgrade to paid."

## What the demo demonstrates

1. Run the naked prompt and read the output aloud — notice how generic and interchangeable it is.
2. Introduce the five-element scaffold: **Audience, Goal, Context, Constraints, Success criteria.**
3. Rewrite the prompt live, filling each element with a real decision.
4. Run the goal-rich brief and compare the two outputs directly.
5. Name specifically what the brief changed — sharper CTA, non-generic value prop, a message tied to a real moment.
6. Close on the three failure modes (over-prescribed, under-specified, vague) to set up the exercise.

## Key takeaway

The model isn't the bottleneck — the brief is. A goal-rich brief is the marketer doing the thinking upfront instead of outsourcing it to a guess.
