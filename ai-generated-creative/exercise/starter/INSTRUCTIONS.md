# One Concept, Three Formats, On Brand

Vessl needs a launch creative set. Using Claude Code as creative director and an AI image tool as the executor, take one concept and produce it as a variant set across three aspect ratios — all on brand.

Work in **Claude Code + an AI image tool of your choice** (any AI image generator you can access). Use:

- [`brand-voice-guide.md`](brand-voice-guide.md) — the brand look, mood, and voice.
- [`creative-brief.md`](creative-brief.md) — the objective, key message, and mandatories.

**No image tool available?** Image generators need their own account, and one may not be signed in on the machine you're working on. If you can't reach one, build the three frames as **HTML/CSS** instead and screenshot them. Everything this exercise assesses still applies — one concept held across three aspect ratios, the brand look-and-feel, and a real critique loop — you'll just be writing layout direction where you'd otherwise write an image prompt. Say which route you took.

## What to produce

- The Claude direction you used, and the self-contained image prompt(s) you wrote — or, on the HTML route, the layout direction.
- The campaign concept produced as three aspect-ratio variants — **1:1** (feed), **9:16** (story/reel), **16:9** (banner) — sharing one concept, brand look, and core message.
- A two-line note explaining one thing you improved by iterating: what was off, what you changed, how it got better.

## Requirements

- Have Claude land one concept first, then write a **self-contained** image prompt that bakes in the brand look, mood, and constraints — the image tool won't remember anything Claude knows.
- Run at least one full critique loop: generate, bring the result back into Claude for feedback against the brand and brief, refine, run it again. Judge the output you actually got, not the one you meant to ask for.
- Keep the concept and brand consistent across all three formats; adapt to the frame, don't start over each time.
- Include the tagline **"Hydration, handled,"** keep on-image copy short and in the brand voice, and follow the look-and-feel (cool aquas and soft blues, clean white base, one warm accent, bright daylight, candid real-life moments, the bottle as hero).

## Done when

You have one concept rendered in three on-brand formats, plus a note that shows you iterated to improve the creative rather than accepting the first generation.
