# Worked Demo — Direct the Concept, Then Generate It

*The real content: the finished walkthrough the demo produces.*

## The value is the direction, not the button-press

Start from [`brand-voice-guide.md`](../exercise/starter/brand-voice-guide.md) and [`creative-brief.md`](../exercise/starter/creative-brief.md), and ask Claude to act as creative director: land on one concept for the launch (the single key message — Vessl keeps score, so you don't have to), then produce two things — a self-contained image prompt and on-brand copy. A brief plus brand voice, turned into a concept and precise prompts, is where marketers win.

## Context doesn't travel between tools

The image tool has none of Claude's context. Everything — the brand look (cool aquas, clean white, one warm accent, bright daylight, candid real moments, the bottle as hero), the mood, the constraints — has to be baked into the prompt you hand it. Writing a self-contained prompt is part of the craft.

## Generate, then critique across tools

Take the prompt into an image tool and generate the visual. AI image tools rarely nail it on the first try. Bring the generated image back into Claude, ask for specific feedback against the brand and brief, carry Claude's refined prompt back to the image tool, and regenerate. Iterating on the prompt — not just re-rolling — is the skill. Hopping between surfaces is friction, but it's how real multi-tool workflows go.

## Hold the concept steady across formats

Have Claude rework the self-contained prompt and copy for a different aspect ratio, keeping concept and brand consistent. Consistency across formats comes from holding the concept and brand steady while you change the frame.

## The pairing

Claude holds the brand, concept, and copy; the image tool executes. You direct, and you carry the context between them.

## Key takeaway

Great AI creative comes from strong direction, disciplined iteration, and carrying your context between tools — not from one magic surface.
