# Demo — Score One Tool Against the Framework

*Instructor demo brief. Estimated running time ~8 minutes. The full worked version is in [`../solution/walkthrough.md`](../solution/walkthrough.md).*

## Setup

- **Scenario:** a marketer is considering one AI copywriting tool and, instead of judging it on a slick demo, runs it through a structured framework.
- **Tools:** the provided [`ai-tool-evaluation-framework.md`](ai-tool-evaluation-framework.md) scorecard; Claude Code (to research and pressure-test the scoring).

## What the demo demonstrates

1. **Framework moment.** Introduce the framework and its scoring dimensions as its own beat — this is the first big idea and deserves room.
2. Score the copywriting tool dimension by dimension, narrating the reasoning (capability, stack fit, cost vs. value, data & privacy, learning curve, and the marketing-specific brand-voice control).
3. Use Claude to stress-test one score ("am I being too generous on integration given we'd copy-paste every draft?").
4. **Build-vs-buy moment.** As its own beat, run the same copywriting task through a general LLM with a good brief and compare. Does the specialized tool actually beat the LLM you already pay for?
5. Total the score and state the verdict in one line: adopt, pilot, or pass — and why.
6. Sketch what the exercise builds toward: a four-way comparison (three tools + DIY baseline) and a short recommendation memo.

## Key takeaway

A structured evaluation converts an impulse into a recommendation. The scorecard isn't bureaucracy — it's what lets you say no to a shiny tool and yes to the right one, with reasons.
