# Sample Output: Delegate, Then Audit a Creator Shortlist

*Illustrative Claude output, a real web-sourced run surfaces real, named creators, then a source-quality audit. One run; live sources and real people's metrics change over time, so if you open these today and find different numbers or names, that is expected, not a mistake in your audit. Names below are shown as generic placeholders (Creator A, etc.) because a live run will return different, real individuals.*

## Delegation brief given to the agent

> **Q:** vetted shortlist of real creators for a creator-led launch of Vessl's smart hydration bottle.
> **Scope:** hydration/wellness, fitness, health/fitness-tech reviewers, sustainability, lifestyle. Per creator: name + platform, audience size + demographics, engagement rate, content style + values, brand-safety flags, rough cost.
> **Output:** claim-by-claim shortlist; a source (link + publish date) for every meaningful claim, naming who asserts it (creator's own vs. independent).
> **Guardrails:** separate self-reported from independent; prefer third-party audience-quality data; flag the unverifiable; stop when scope is covered.

## Returned shortlist (excerpt the learner audits)

> 1. **Creator A (fitness).** ~1.2M followers, positive "feel-good" fitness tone. *(follower count: live platform profile, accessed 2026-09-26)*
> 2. **Creator A engagement: 8%.** *(creator's media kit, self-reported, accessed 2026-09-26)*
> 3. **Creator B (lifestyle).** "16M reach across platforms." *(creator bio / press blurb, self-reported, accessed 2026-09-26)*
> 4. **Creator C (gadget reviewer).** Sponsorship "~$25–40k per video." *(industry estimate, no rate card named, accessed 2026-09-26)*
> 5. **Creator D (sustainability).** Strong values fit, featured in named national outlets. *(named magazine + newspaper features, published 2024–2025, accessed 2026-09-26)*

## The audit that follows

- **Claim 1 (reach, Creator A):** on the live profile, independent enough, matches. **Trust**, for reach only.
- **Claim 2 (engagement, Creator A):** self-reported 8% vs. ~1.9% from a third-party tool. Real source, but the number doesn't hold. **Verify-first**, do not use 8%.
- **Claim 3 (reach, Creator B):** self-reported 16M vs. ~2M independent, an ~8x gap. **Drop** the 16M; use ~2M and re-verify.
- **Claim 4 (cost, Creator C):** no rate card, no named source. **Drop** as a number; placeholder until a quote confirms it.
- **Claim 5 (values, Creator D):** named reputable outlets, articles exist and support it. **Trust**.

## Two-line verdict

> **Ready for outreach:** Creators A (reach only) and D (values, verified) go forward; both screened for brand-safety.
> **Verify before budget:** Creator A's engagement rate (self-reported 8% vs ~1.9% independent), Creator B's reach (16M self-reported vs ~2M independent), and every cost figure (none independently confirmed). No budget moves on a self-reported number.

*The lesson: the reach can be real while the engagement rate, self-reported in a media kit, is inflated 4x. Auditing the source list instead of opening an independent tool would have waved it through.*
